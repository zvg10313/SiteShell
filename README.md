# macOS 风格网页截图生成器

一个简单易用的纯前端网页截图生成工具，可以为任意网页生成精美的 macOS 浏览器风格带壳截图。

## 功能特点

- 🖥️ macOS 浏览器风格：包含经典的红黄绿窗口控制按钮和地址栏
- 🌐 多代理支持：内置多个代理服务，解决跨域问题
- 📥 多格式输出：支持 PNG 和 JPEG 格式，JPEG 可调节质量
- 📱 响应式设计：完美支持手机和电脑访问
- ⚡ 纯前端实现：无需后端，直接在浏览器中运行
- 🎨 可自定义：可选择是否显示地址栏和窗口控制按钮
- 🔍 灵活缩放：支持百分比缩放和自定义宽高调节
- 🎭 多样背景：提供纯白、渐变、网格、点阵四种背景样式
- ✂️ 拖拽裁剪：通过拖拽底部手柄精确控制显示范围

## 快速开始

### 本地运行

1. 克隆或下载本项目
2. 直接用浏览器打开 `index.html` 文件即可使用

### 部署到 GitHub Pages

1. 将项目上传到 GitHub 仓库
2. 进入仓库的 **Settings** → **Pages**
3. 在 **Source** 下选择 **Deploy from a branch**
4. 选择 `main`（或 `master`）分支和 `/ (root)` 目录
5. 点击 **Save**
6. 等待几分钟后，访问生成的 URL 即可

## 使用方法

1. **输入网址**：在输入框中输入要截图的网页 URL
2. **选择代理**：根据需要选择代理服务（推荐使用 AllOrigins）
3. **调整缩放**：
   - 使用百分比滑块快速调整整体缩放（50%-150%）
   - 或输入自定义宽度和高度精确控制尺寸
   - 点击"应用"按钮应用自定义尺寸
   - 点击"重置"按钮恢复默认设置
4. **生成预览**：点击"生成截图"按钮
5. **下载截图**：点击"📥 下载截图"按钮保存图片

## 代理服务说明

本工具提供以下代理服务：

- **不使用代理**：直接访问目标网站（可能受 CORS 限制）
- **AllOrigins (推荐)**：稳定可靠的代理服务
- **CORS Proxy**：另一个流行的 CORS 代理
- **ThingProxy**：备选代理服务

如果页面无法加载或截图为空白，请尝试切换不同的代理服务。

## 注意事项

- 由于浏览器安全限制（CORS 策略），部分网站可能无法在 iframe 中显示
- 某些网站设置了 `X-Frame-Options` 或 `Content-Security-Policy` 头，会阻止 iframe 嵌入
- 如果遇到跨域问题，请尝试使用不同的代理服务
- 截图质量取决于目标网站的加载速度和代理服务的稳定性

## 常见问题

### Q: 为什么有些网站无法加载？

A: 部分网站设置了安全策略禁止 iframe 嵌入，这是正常现象。可以尝试使用代理服务。

### Q: 截图为什么是空白的？

A: 可能是跨域问题导致的。请尝试切换到不同的代理服务，或者使用同源网站。

### Q: 可以截图 HTTPS 网站吗？

A: 可以，但需要确保代理服务支持 HTTPS。本工具内置的代理服务都支持 HTTPS。

### Q: 截图的分辨率是多少？

A: 默认使用 2 倍缩放（scale: 2），可以生成高清截图。

### Q: 如何调整截图的大小？

A: 可以使用以下两种方式：
- **百分比缩放**：拖动滑块在 50%-150% 之间快速调整
- **自定义尺寸**：输入具体的宽度和高度（像素），然后点击"应用"按钮

### Q: 缩放会影响截图质量吗？

A: 不会。缩放只影响预览时的显示大小，下载的截图始终是高清的（2 倍缩放）。
